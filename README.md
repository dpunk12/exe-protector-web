# ExeShield

Initial commit. Project scaffolding will be added by the coding agent in the first pull request.

ExeShield is a cPanel-hostable web application that lets you upload a Windows
`.exe` and download a protected version whose original bytes are AES-256
encrypted. The protected exe self-decrypts and runs the original program at
runtime.

This project is being developed with full accessibility in mind for blind and
low-vision developers and users.
